# Sound bank

The game loads each effect by name from this folder, preferring `<name>.ogg`
and falling back to `<name>.wav`. The files shipped here are soft procedural
placeholders generated by `tools/gen_sounds.py` — fine to ship, but you can
replace any of them with a hand-picked sound.

## How to swap a sound

1. Find a short clip (a few seconds max) — freesound.org, kenney.nl, or any
   royalty-free SFX pack works well.
2. Export it as **OGG** (Vorbis). OGG is required for the web/itch build —
   pygbag rejects WAV. The desktop build accepts either.
3. Save it in **this folder** (`view/sounds/`) using the exact name below.

That's it — no code change needed. If a file is missing the game just stays
silent for that effect.

## Files the game expects

| File         | When it plays                                  | Good search terms              |
|--------------|-------------------------------------------------|--------------------------------|
| `hover.ogg`  | cursor lands on a tile                          | "ui hover", "soft tick"        |
| `spread.ogg` | the value-match highlight fans out (after 0.5s) | "ui shimmer", "soft sparkle"   |
| `click.ogg`  | a menu / button is pressed                      | "ui click", "button click"     |
| `pick.ogg`   | a small tile is cleared                         | "pop", "bubble pop", "blip"    |
| `solve.ogg`  | a cell is solved (big tile appears)             | "success chime", "ding"        |
| `wrong.ogg`  | a wrong tile is clicked (a life is lost)        | "error", "wrong buzzer", "thud"|
| `win.ogg`    | the puzzle is solved                            | "win fanfare", "level complete"|
| `lose.ogg`   | all lives are lost                              | "game over", "fail"            |
| `start.ogg`  | a new board cascades in                         | "whoosh", "swoosh transition"  |

## Regenerating the placeholders

```
pip install imageio-ffmpeg     # one-time: provides the OGG encoder
python3 tools/gen_sounds.py
```

Without an ffmpeg encoder the generator falls back to writing `.wav` — those
play fine on desktop but must be converted to `.ogg` before the web build.
