# Einstein — ревью и план развития

Целостное ревью игры в трёх ролях (геймдизайнер · UI/UX-художник · издатель)
и оформление страницы itch.io. Фокус — **дешёвые быстрые улучшения**; крупные
изменения откладываем до теста на живых игроках.

Игра: логическая головоломка-дедукция (загадка Эйнштейна / зебра-пазл на
сетке). Поле N×N (4/5/6), каждая строка — категория из N символов, подсказки
ограничивают столбцы. Игрок лопает неверных кандидатов → клетки решаются →
каскад → поле заполняется.

---

## 1. Геймдизайн

**Сильное**
- Ядро петли работает: прочитал подсказку → лопнул → каскад → поле заполнилось.
  **Каскад — главная жемчужина геймфила**: одна дедукция запускает цепочку —
  это «oddly satisfying».
- Каждый пазл гарантированно решаем (`SelfWalkthrough` проверяет) — **угадывать
  не нужно**. Для логической головоломки это знак качества — стоит вынести в
  описание.
- Новый туториал из 6 блоков даёт нормальную кривую входа.
- Символы несут информацию (не только цвет) → дружелюбнее к дальтоникам.

**Слабое / риски**
- Это **объективно сложный пазл** (загадка Эйнштейна пугает). 6×6 Hard — очень
  тяжело; казуальный игрок отвалится.
- Мета-прогрессия тонкая: только статистика по сложностям. Нет причины вернуться
  завтра.
- Поражение (кончились жизни) на сложном поле = потерянный прогресс, наказание.
- Нет «снекового» входа — даже 4×4 это заход надолго.
- Реиграбельность: пазл одноразовый, нет ежедневного крючка.
- Нет ачивок/коллекционирования для неигроков в пазлы.

**Быстрые дешёвые улучшения (по приоритету)**
1. **Daily Puzzle** — один пазл в день, сид RNG = дата. Причина возвращаться +
   естественный повод поделиться. Дёшево. ★ максимальный ROI по удержанию.
2. **Ачивки / бейджи** — «Первая победа», «Без ошибок», «Быстрее пара»,
   «Туториал пройден», «Серия ×5», «6×6 Hard». Статистика уже считается —
   осталось показать как коллекцию. Драйв для неигроков в пазлы.
3. **Счётчик серии** (подряд побед / дней) в меню. Крошечный код, залипательно.
4. **На поражении — «Перепройти это же поле»**, а не только новое. Превращает
   фейл в обучающий ретрай, удерживает фрустрированного игрока.
5. **Казуальная сетка безопасности** — режим Zen: без жизней/таймера (или жизни
   без game-over). Либо первая ошибка на Easy — бесплатная.
6. **Режим 3×3 «Quick»** — генератор уже есть (туториал). 30-секундные сессии и
   готовый материал для гифок. Почти бесплатно.
7. **Строка-шеринг на финале** — «Решил 6×6 за 2:14, 3★» с копированием.
   Бесплатная виральность.
8. **Челлендж для ветеранов** — модификатор «Hard+ / без права на ошибку /
   меньше подсказок» или еженедельный самый сложный пазл.

> Принцип: слоить цели — сессионная (реши поле) уже есть; добавить
> краткосрочную (звёзды, серия) и долгосрочную (ачивки, daily-streak).

## 2. Арт / UI-UX

**Сильное** — полировка уже выше среднего itch-пазла:
- Скруглённые AA-плитки, дизер-градиенты (без бандинга), мягкие тени,
  hover glow + lift + hop, пружинные easing, каскад-попы, конфетти, частицы
  разбитого сердца, screenshake, виньетка, 3 цельных палитры, разрядка в
  заголовках, скин веб-загрузчика.
- Единый язык анимации («догоняем анимированную цель»).
- Тултипы переводят абстрактные маркеры подсказок.

**Возможности**
- Абстрактные глифы подсказок (↕ ↔ …) всё равно требуют привыкания — туториал и
  тултипы помогают; можно добавить маленькую постоянную легенду.
- При 6×6 поле визуально «шумит» от кандидатов.
- **Нет музыки** — только SFX. Мягкий эмбиент-луп сильно поднимает «уют» и стоит
  дёшево (один CC0-трек).
- Сам момент решения клетки можно «насочнее».

**Быстрые улучшения (juice / vfx — см. «Juice it or lose it», «Art of
Screenshake»)**
1. **Звук**: тихий эмбиент/лоу-фай-луп (CC0) + **повышение тона** попа по мере
   роста цепочки каскада (combo-pitch). Одно это делает каскады залипательными.
2. **Рябь каскада**: при решении клетки — быстрое расходящееся кольцо/волна,
   подталкивающая соседей. Усиливает ощущение цепочки.
3. **Combo-текст**: всплывающее «+3 chain!», когда один клик решает несколько
   клеток — мини-дофамин из каскада.
4. **Idle-мерцание** поля, чтобы статичный скрин/гифка были живыми.
5. **Настройка reduce-motion** — тумблер для чувствительных к тряске.
6. Держать минимализм — сдержанность здесь сила, не перегружать.

> Эти же эффекты — готовый материал для гифок/шортсов.

## 3. Издатель / маркетинг

**Аудитория**
- Ядро: любители логических пазлов (Sudoku, Picross, нонограммы, зебра-пазлы).
- Охват: казуальные зрители «oddly satisfying / cozy puzzle».

**Виральность и хук**
- Виральный вектор — **каскад**. Это эталонный «satisfying»-контент. Юнит для
  шеринга = короткий вертикальный клип цепного решения поля + чистый «пис» попа.
- Крючок «остаться» — каскад + «ещё разок»; крючок «вернуться» — Daily Puzzle.

**Что улучшить (под itch + рост аккаунта, бесплатно)**
- **Веб-версия в браузере — главный рычаг**: нулевой порог входа. Убедиться, что
  на странице itch стоит HTML5-эмбед (играют прямо на странице).
- Полные теги, заявка в itch-коллекции/бандлы пазлов, devlog (itch продвигает
  devlog'и), участие в community-тредах.
- Мост казуал ↔ хардкор: селектор сложности уже есть; добавить Zen (казуал) +
  еженедельный сложный челлендж (хардкор). Звёзды/ачивки — казуалам,
  пар-тайм/серии/без-ошибок — ветеранам.
- **Юмор**: у игры уже есть дерзкий голос («you broke the game!», «drink some
  coffee»). Закрепить этот тон — в туториале, экранах поражения, описании
  страницы, подписях к гифкам.
- **Шортсы (3 клипа)**: (1) сочное каскадное решение; (2) «как это работает за
  10 сек»; (3) комедийный fail→retry. Вертикаль, <15 сек, луп.

## 4. Страница itch.io и обложка

**Обложка** (630×500). Концепт: поле 6×6 в момент каскада — диагональная волна
клеток, превращающихся из сеток-кандидатов в крупные глифы; тёмный mocha-фон,
6 точек-цветов рядов, заголовок «EINSTEIN» в разрядку. Одна палитра. Минимализм.

**Структура страницы** (минимум текста, играбельный эмбед сверху):
1. HTML5-эмбед (Kind of project: HTML, залить zip, «This file will be played
   in the browser»).
2. Слоган одной строкой.
3. 1 герой-гифка (каскадное решение) → 2-3 скриншота.
4. «How to play» — 3 коротких шага с иконками правил.
5. Список фич — эмодзи-буллеты.
6. Разделители (`◆ ─────── ◆` или `· · · · ·`).
7. Футер: призыв к рейтингу/комментарию.

**Готовый текст (копипаст, EN)**

Слоган:
> *Einstein's riddle — the satisfying kind. One clue, and the whole board
> cascades into place.*

How to play:
> 1. Every cell hides symbols — ❌ pop the wrong ones.
> 2. Read the clues — ↕ same column · ↔ neighbours · … left-of.
> 3. The last symbol standing solves the cell — and chains into the next. 🌊

Features:
> - 🧩 Pure logic — every puzzle is **guaranteed solvable**, never a guess
> - 🌊 Watch one deduction cascade across the whole board
> - 🎚️ 4×4 → 6×6, three difficulties — coffee-break to brain-melt
> - ⭐ Stars, scores & best times to chase
> - 🎓 A hands-on tutorial that eases you in — no wall of text
> - 🎨 Three cosy themes · plays in your browser · mouse or touch

Футер (с юмором + призыв):
> *◆ ─────────────── ◆*
> 98% of people bounce off logic puzzles. This one is built so you actually
> finish — and feel smart doing it.
> ⭐ **If it made your brain feel good, leave a rating and a comment** — it
> genuinely pushes a tiny dev account forward. Thank you! 🙏

**Теги itch**: `puzzle`, `logic`, `minimalist`, `relaxing`, `sudoku`,
`brain-training`, `singleplayer`, `html5`, `deduction`, `casual`.

**Гифки/шортсы для соцсетей**
- Гифка-герой: каскад из ~6+ клеток подряд, чистый звук.
- Шортс 1: тот же каскад, вертикаль, подпись с юмором.
- Шортс 2: «решаем загадку Эйнштейна за 15 секунд» (3×3 Quick).
- Шортс 3: fail → «retry same board» → победа (мини-арка).

## 5. План — быстрые шаги по приоритету

| # | Что | Стоимость | Эффект |
|---|-----|-----------|--------|
| 1 | Daily Puzzle (сид = дата) | низкая | удержание ★ |
| 2 | Ачивки/бейджи + счётчик серии | низкая | неигроки в пазлы |
| 3 | «Перепройти это же поле» на поражении | низкая | удержание |
| 4 | Zen-режим (казуал) | низкая | охват аудитории |
| 5 | Эмбиент-музыка + combo-pitch + рябь каскада | низкая-средняя | геймфил, гифки |
| 6 | Строка-шеринг результата | низкая | виральность |
| 7 | Режим 3×3 Quick | низкая | снек + контент |
| 8 | Оформить страницу itch + 3 шортса | низкая | трафик |
| 9 | Еженедельный сложный челлендж | средняя | хардкор-аудитория |

Сначала 1-4 (удержание + охват), потом 5-8 (геймфил + трафик), 9 — после теста.
